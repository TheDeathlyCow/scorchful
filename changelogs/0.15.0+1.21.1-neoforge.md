# Scorchful 0.15.0 for Minecraft NeoForge 1.21.1

Scorchful has been ported to Neoforge! This port is possible thanks to [Forgified Fabric API](https://github.com/Sinytra/ForgifiedFabricAPI) and the [Yumi Minecraft Foundation Library](https://github.com/YumiProject/yumi-minecraft-foundation-library). Big thanks to them for making this relatively easy to do!

This port is roughly equivalent to the latest Scorchful for 1.21.1, `0.15.11+1.21.1`.

**Please note that this is an experimental Neoforge port of Scorchful.** It is still in alpha, and therefore may contain bugs and cause crashes. This port has also been created in a 'Fabric-like' manner using Forgified Fabric API and custom entry points to minimize the changes needed from the original version, which means that it may not work very well with the Neoforge ecosystem. Proceed with mild caution and please feel free to report issues to the [issue tracker](https://github.com/TheDeathlyCow/scorchful/issues).

**Scorchful remains a Fabric-first mod and this port is not likely to be updated to new Minecraft versions regularly.**
