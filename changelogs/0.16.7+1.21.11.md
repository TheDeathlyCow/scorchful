# Scorchful 0.16.7+1.21.11

* Updated Immersive Storms version to 1.5.0
* Remap Scorchful codebase to Mojmap to prepare for 26.1
* Switched to using a more resilient method for registering player attributes to prevent missing attribute crashes in modpacks
* Changed the ID of the Rehydration Efficiency attribute from `scorchful:player.rehydration_efficiency` to `scorchful:rehydration_efficiency`
  * This change has been aliased so existing worlds and datapacks will work.
* Fixed a bug that caused infinite Rehydration drink fills when not being warmed.
